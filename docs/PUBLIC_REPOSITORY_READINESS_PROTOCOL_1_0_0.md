# Public repository readiness protocol

Authorization: `TS-DETECTABILITY-PUBLIC-REPOSITORY-READINESS-1.0.0-P6F2`  
Protocol: `1.0.0`  
Phase: `6F.2`

Create RC3 separately from immutable RC2. Permitted changes are public-path
sanitization, narrowly scoped ignore-policy hardening, public documentation,
privacy/payload review evidence, and deterministic RC3 packaging.

Scientific and source-data changes are zero. Git initialization, remote
creation, uploads, releases, DOI actions, and scientific execution are
forbidden. Validation and completion are fail-closed and completion is written
last.
