# Official attribution evidence v1.0.0

Current official primary sources were consulted; no permission was inferred beyond their stated guidance.

- **NASA Exoplanet Archive acknowledgment and citation** — Acknowledge archive services and cite current archive reference; cite source-specific literature.  
  https://exoplanetarchive.ipac.caltech.edu/docs/acknowledge.html  
  Applicability: `APPLIES_TO_CATALOG_PROVENANCE`.
- **MAST mission acknowledgments** — Use current TESS/MAST mission acknowledgment for publications using archived products.  
  https://archive.stsci.edu/publishing/mission-acknowledgements  
  Applicability: `APPLIES_TO_TESS_PRODUCTS`.
- **TESS publication acknowledgment** — Acknowledge TESS mission data and NASA Science Mission Directorate funding.  
  https://heasarc.gsfc.nasa.gov/docs/tess/publications.html  
  Applicability: `APPLIES_TO_TESS_PRODUCTS`.
- **TESS documentation and source papers** — Cite mission, catalog, and SPOC processing papers where applicable.  
  https://heasarc.gsfc.nasa.gov/docs/tess/documentation.html  
  Applicability: `APPLIES_TO_MISSION_AND_PIPELINE_CONTEXT`.
- **NASA brand guidelines** — NASA insignia, logotype, seal, and identifiers have restricted use and must not imply endorsement.  
  https://www.nasa.gov/nasa-brand-center/brand-guidelines/  
  Applicability: `NO_BRANDING_INCLUDED`.
- **Zooniverse citation guidance** — Acknowledge Zooniverse where Zooniverse-generated data are used.  
  https://www.zooniverse.org/about/resources  
  Applicability: `NOT_APPLICABLE_DATA_NOT_USED`.
- **Zenodo record metadata** — A deposit requires resource type, title, publication date, creators, and other record metadata.  
  https://help.zenodo.org/docs/deposit/create-new-upload/  
  Applicability: `FUTURE_DEPOSIT_ONLY`.
- **Zenodo mixed licenses** — Mixed-license uploads may declare more than one license.  
  https://help.zenodo.org/docs/deposit/describe-records/licenses/  
  Applicability: `FUTURE_DEPOSIT_ONLY`.
- **Zenodo DOI behavior** — A DOI may be reserved before publication or registered on publication; no action is authorized here.  
  https://help.zenodo.org/docs/deposit/describe-records/reserve-doi/  
  Applicability: `FUTURE_DEPOSIT_ONLY`.
