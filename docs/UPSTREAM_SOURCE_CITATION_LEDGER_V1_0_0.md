# Upstream source citation ledger v1.0.0

The frozen catalogue comes from the NASA Exoplanet Archive `pscomppars` table;
TESS light curves come from MAST; recovery and injection/model endpoints are
first-party derived. Archive records can aggregate values from source-specific
literature. RC1 preserves the local provenance chain and official service
acknowledgments, while a publication bibliography must still resolve the
applicable row-level source papers. No bibliography entry was invented.
