# TESS Transit Detectability Benchmark: A Reproducible Injection–Recovery and Statistical Modeling Study

Version: `1.0.0-rc.1` — release candidate for independent review, not publicly released.

Author: Radhe Dhoundiyal  
Affiliation: Independent student researcher

This fixed benchmark contains 40 targets, 320 normalized injection trials,
eight target-grouped folds, 68 converged model fits, and 14 validated figures.
It is descriptive/predictive within the frozen benchmark and makes no universal
or causal completeness claim.

Primary Model A metrics are preserved from terminal authority: log loss
0.3198223626785455, Brier score 0.1046725568285409, ROC AUC
0.9257676043390329, and PR AUC 0.8056516447845964. Interaction improvement
0.0038141055083467 was below the frozen 0.005 threshold and was not retained.
